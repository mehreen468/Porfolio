# Portfolio Website

This repository contains a static game developer / software engineering portfolio website built with HTML, CSS, and Bootstrap.

## Features

- Responsive single-page portfolio layout
- 3D-inspired hero cube animation using CSS transforms
- Sections for About, Projects, Skills, and Contact
- Ready for GitHub Pages deployment

## Run locally

1. Open `index.html` in your browser
2. Or use a simple local server like Live Server in VS Code

## Deploy to GitHub Pages

1. Push this repository to GitHub
2. Enable GitHub Pages in repository settings
3. Set the branch to `main` (or `master`) and the `/root` folder
4. Your portfolio will be available at `https://<username>.github.io/<repository>`

## Customize

- Edit `index.html` to replace placeholder text
- Update `css/style.css` for your own branding
- Add your own project links and images
